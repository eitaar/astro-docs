Astroでは、画像がプロジェクト内にローカルで保存されているか、外部URLからリンクされているか、CMSやCDN上で管理されているかに関係なく、サイト上で画像を扱うための複数の方法を提供しています。

Astroでは、組み込みの[`<Image />`](#image-)コンポーネントと[`<Picture />`](#picture-)コンポーネント、[Markdown画像構文](#images-in-markdown-files)(`![]()`)の処理、[SVGコンポーネント](#svg-components)、および[画像生成関数](#generating-images-with-getimage)を使用して、画像の最適化や変換をおこなえます。また、デフォルトで[レスポンシブ画像の自動リサイズ](#responsive-image-behavior)を設定したり、個々のimageコンポーネントやpictureコンポーネントにレスポンシブプロパティを指定したりすることもできます。

もちろん、標準的なHTMLを使用して`.astro`やMarkdownファイルに画像やSVGファイルを表示することも、ファイルの種類に応じた標準的な方法（MDXやJSXで`<img />`を使用するなど）で表示することも可能です。ただし、Astroはこれらの画像に対して処理や最適化を一切行いません。

また、Astroにはネイティブな動画サポートがありません。そのため、最適化やストリーミングといった要件に対応するために[動画ホスティングサービス](/ja/guides/media/)を利用することを推奨します。

<ReadMore>[`<Image />`](/ja/reference/modules/astro-assets/#image-)および[`<Picture />`](/ja/reference/modules/astro-assets/#picture-)コンポーネントの完全なAPIリファレンスを確認してください。</ReadMore>

## 画像の保存場所

### `src/` vs `public/`

Astroによる画像の変換、最適化、およびバンドル機能を活用するため、ローカル画像は可能な限り`src/`内に保存することを推奨します。`public/`内に保存されたファイルは、処理されることなく配信されるか、ビルドフォルダにコピーされます。

`src/`内に保存された画像ファイルは、`.astro`、`.md`、`.mdx`、`.mdoc`、およびその他のUIフレームワークのコンポーネントを含む、プロジェクト内のすべてのファイルで通常のファイルインポートと同じように使用できます。画像はコンテンツと同じフォルダ内を含む、任意のフォルダに保存できます。

画像に処理を加えたくない場合は、画像を`public/`フォルダ内に保存してください。このフォルダ内に保存された画像は、ドメイン上のURLパスとしてプロジェクト内のファイルから参照できるほか、画像に直接アクセス可能な公開URLとしても機能します。例えば、faviconはブラウザが正しく認識できるよう、通常は`public/`直下に配置されます。

### リモート画像

ローカルに保存する以外にも、[コンテンツ管理システム(CMS)](/ja/guides/cms/)や[デジタルアセット管理(DAM)](/ja/guides/media/)プラットフォームなどを使用して外部に画像を保存できます。AstroではAPIを使用して外部からデータを取得したり、完全なURLを指定して画像を表示したりすることも可能です。

外部ソースを扱う際の安全性を高めるため、Astroの画像コンポーネントおよびヘルパー関数は、[設定で指定された承認済みの画像ソース](#authorizing-remote-images)からの画像のみを処理します。未承認のソースからインポートされた画像は処理されず、そのまま表示されます。

## `.astro`ファイル内の画像

<p>

**オプション:** `<Image />`, `<Picture />`, `<img>`, `<svg>`, SVGコンポーネント
</p>

Astroのテンプレート言語では、[`<Image />`](/ja/reference/modules/astro-assets/#image-)コンポーネントを使用して画像を最適化して表示したり、[`<Picture />`](/ja/reference/modules/astro-assets/#picture-)コンポーネントで異なるサイズやフォーマットの画像を生成したりできます。また、どちらのコンポーネントも、画面サイズや解像度に応じて画像サイズを調整する[レスポンシブ画像プロパティ](#responsive-image-behavior)をサポートしています。

さらに、`.astro`コンポーネント内でSVGファイルをインポートし、[SVGファイルをAstroコンポーネントとして使用](#svg-components)することもできます。

`<img>`や`<svg>`を含む標準的なHTMLタグを使用して、`.astro`ファイル内で画像を使用することもできます。ただし、[HTMLタグでレンダリングされた画像](#display-unprocessed-images-with-the-html-img-tag)は画像処理(変換、最適化など)が一切行われないまま、元の状態のままビルドフォルダにコピーされます。

`.astro`ファイル内のすべての画像において、**画像の`src`属性の値は、画像ファイルの場所によって決まります**。

- プロジェクトの`src/`フォルダに保存されている画像を使用する場合は、そのファイルの相対パスからインポートを行います。

  ImageコンポーネントやPictureコンポーネントでは、インポートした変数名をそのまま渡します(例：`src={rocket}`)。一方、HTMLの`<img>`タグを使う場合は、オブジェクトのsrcプロパティを参照する必要があります(例：`src={rocket.src}`)。

- リモート画像および`public/`フォルダ内の画像を表示する場合は、URLパスを使用します。

  リモート画像を使用する場合は、完全なURLパス(例: `src="https://www.example.com/images/my-remote-image.jpg"`)を指定します。`public/`フォルダ内の画像を使用する場合は、その場所に対応する相対URLパスを指定できます(例: `public/images/my-public-image.jpg`にある画像の場合は`src="/images/my-public-image.jpg"`)。

```astro title="src/pages/blog/my-images.astro"
---
import { Image } from 'astro:assets';
import localBirdImage from '../../images/subfolder/localBirdImage.png';
---
<Image src={localBirdImage} alt="鳥が巣で卵を温めている。" />
<Image src="/images/bird-in-public-folder.jpg" alt="鳥。" width="50" height="50" />
<Image src="https://example.com/remote-bird.jpg" alt="鳥。" width="50" height="50" />

<img src={localBirdImage.src} alt="鳥が巣で卵を温めている。">
<img src="/images/bird-in-public-folder.jpg" alt="鳥。">
<img src="https://example.com/remote-bird.jpg" alt="鳥。">
```

## Markdownファイル内の画像

<p>

**オプション:** `![]()`, `<img>` (`public/`フォルダ内の画像かリモート画像の場合)
</p>

`.md`ファイルでは通常のMarkdown構文`![]()`を使用してください。画像が`src/`フォルダまたは承認されたリモートサーバーに保存されている場合、画像は自動的に変換および最適化されます。[レスポンシブ画像をグローバルに設定](/ja/reference/configuration-reference/#imagelayout)すればこれらの画像も[レスポンシブ](#responsive-image-behavior)対応になります。

`public/`フォルダ内の画像は最適化されません。

```md
<!-- src/pages/post-1.md -->

# 私のMarkdownページ

<!-- src/assets/に保存されているローカル画像 -->
<!-- 相対ファイルパスまたはインポートエイリアスを使用してください -->
![満天の星空。](../assets/stars.png)

<!-- public/images/に保存されているローカル画像 -->
<!-- public/からの相対パスを使用してください -->
![満天の星空。](/images/stars.png)

<!-- 他のサーバーに保存されているリモート画像 -->
<!-- 画像のフルURLを使用してください -->
![Astro](https://example.com/images/remote-image.png)
```

HTMLの`<img>`タグを使用して、`public/`ディレクトリや外部に保存されている画像を、処理や最適化を行わずにページに表示させることもできます。ただし、`src/`内のローカル画像の表示には対応していません。

また、`<Image />`および`<Picture />`コンポーネントは`.md`ファイルでは利用できません。画像の属性を細かく制御する必要がある場合は、[AstroのMDXインテグレーション](/ja/guides/integrations-guide/mdx/)を使用して、`.mdx`形式をサポートすることをおすすめします。MDXを使用すると、AstroコンポーネントとMarkdown構文を組み合わせるなど、[MDXで利用可能な追加の画像オプション](#images-in-mdx-files)が使えるようになります。
